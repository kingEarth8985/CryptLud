About CryptLud

CryptLud is a steganography tool that hides secret messages using zero-width characters — invisible Unicode characters that take up no visible space.

Technical Details

Encoding Process:

  • Secret message is converted to UTF-8 bytes
  • Each byte is converted to 8 bits
  • Bit 0 → Zero-Width Space (U+200B)
  • Bit 1 → Zero-Width Non-Joiner (U+200C)
  • Invisible bits are appended to visible text

Decoding Process:

  • Zero-width characters are extracted from text
  • Characters are converted back to bits
  • Bits are grouped into bytes
  • Bytes are decoded as UTF-8 text
